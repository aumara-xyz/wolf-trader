# mv-abi provenance

Vendored from `aumara-xyz/aukora-microverse`, `cells/abi` (Microverse ABI v1
reference implementation), to keep the Aukora decision kernel on the same
canonical-JSON contract without a cross-repository path dependency.

- Source: `cells/abi/src/lib.rs` and `cells/abi/Cargo.toml`
- Upstream contract: `ABI.md` in the same repository
- Local change: none; the crate is consumed as-is
